## Scope and completion rule

Deliver attended Claude Ask-web public research for Joe and named staff with current areas/record rights: anonymous/public contexts, exact person-reviewed public URLs, bounded live view, public observations, FIFO queue, desktop/Safari-iPad take-over, phone viewing, Stop, expiry, recovery and Joe Watch. **Every manual event first makes the context permanently private.** Vault dependency stays `none`; Done leaves it paused. An explicitly confirmed fresh browser destroys the old context and creates a new anonymous generation on the same live task/sites, without copying state.

**No outside writes**, including login/POST search, company/private-value GET lookup, autosave, upload, payment or signature, whether model- or person-driven. No saved logins, profile persistence, file saves, final approval/dispatch, city adapters or staff-to-Joe handoffs. Public read confirmations are real decisions; blocked-write cards explain a refusal, never offer a functioning approval. Later-phase wireframes are future fixture variants, not enabled functionality.

Completion requires A–D integration, named regression gates, then coordinator runtime/device/transport acceptance of the exact frozen candidate. Builder tests cannot expose take-over or set release readiness. Staff parity is required for Phase 1 acceptance even though activation starts with Joe.
