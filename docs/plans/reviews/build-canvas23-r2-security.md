With a supplied versionId, resolveDesign uses getPlanDesign/getPlanDesignVersion (lib/plan-designs.ts:167,228), which are plain database readers with no permission enforcement. A staff member with Projects but without Leads can render and file a lead's saved drawing, including lead details, despite being refused the live-snapshot path. This is in the publication path explicitly revised and requested for round 2 review; the selected-history branch predates the fix but remains an authorization gap.

   **Exact change:** authorize the locked target design for both branches before reading snapshot content, lead details, captures, rendering or writing files. For selected history, resolve the snapshot under that authorization and require its design_id to match the authorized design. Keep automatic snapshot allocation under the same lock; return a fixed unavailable result for denied targets. Prefer a shared authorized resolver so renderPlanSheetsPdf cannot reach the same unguarded resolveDesign path. Add negative action tests for Projects-only staff versus a lead with a selected snapshot and a foreign-design snapshot, plus authorized controls; denied calls must never reach PDF/file effects.

2. **Medium — perform estimate source authorization before draft insertion and diagnostics.** lib/actions/plan-estimate.ts:108–132 reads the design and inserts an estimate at line 121 before pinnedVersionFor finally checks Projects/scoped Leads. A caller with Estimates and Projects but without Leads can repeatedly create drafts on a denied lead. The later authorization error does not roll back the earlier autocommitted INSERT. Denied source access must return a fixed unavailable result before any estimate mutation or target-specific diagnostics. Ensure a failed authorization cannot leave a draft behind. Add regression cases for Estimates+Projects without Leads against a lead, and Estimates without Projects against a project, asserting zero estimate inserts and zero snapshot/line writes.

   **Concrete repro:** as active Estimates+Projects staff without Leads, invoke generateEstimateFromDesign(leadDesignId, {}). An estimate is inserted on that lead before CANVAS_UNAVAILABLE is thrown.
