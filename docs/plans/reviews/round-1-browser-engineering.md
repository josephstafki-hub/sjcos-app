## Wrong or invented

- **§9.2 cannot call the existing grant consumer as specified.** §7.3 calls `consumeGrantRun` inside the atomic service consume operation. It is TypeScript executing SQL through a supplied `Run`, not a PostgreSQL routine (`lib/dispatch/authority.ts:227–253`). Yet §9.2 denies the service direct grant writes and exposes a SQL SECURITY DEFINER consume function. Neither existing code nor the proposed interface bridges these two execution environments.
- **§9.1's composite current-run parent conflicts with §4's multi-turn task.** Historical actions reference `(task_id,run_id,initiator)` in `browser_tasks`, whose single `run_id` must change on the next turn. RESTRICT prevents attachment of the next run once an action references the old tuple; cascading the update would rewrite approval history. There is no immutable task/run association table or equivalent specified.
- **§3.2's private-FD handoff is not provided by the cited launch stack.** The current runner spawns Claude without extra stdio descriptors (`scripts/run-claude-agent.mjs:715`); installed MCP SDK stdio spawning explicitly supplies only descriptors 0–2 (`/home/joe/sjcos-app/node_modules/@modelcontextprotocol/sdk/dist/esm/client/stdio.js:65–75`). The plan supplies no supported Claude-to-MCP descriptor forwarding or alternate authenticated rendezvous.
- **§3.2 overstates proxy credential isolation.** In the pinned 1.64.1 bundle, `authenticateProxyViaCredentials` puts proxy credentials into origin-unscoped HTTP credentials (`coreBundle.js:53275–53281`); `_onAuthRequired` supplies matching credentials without checking challenge source (`:37519–37534`; matcher `:52894–52897`). Therefore using ordinary Playwright proxy options does not establish “internal auth cannot reach the destination.” Also, an end-to-end TLS CONNECT proxy cannot inspect the encrypted HTTP Host header as §8.1 promises without a different mechanism.
- **§8.2 names the wrong existing file tool.** There is no registered `fetch_project_file`; the real tool is `get_project_file`, with base64/url/text/pages variants and sessionless signed URL generation (`mcp/bidding-tools.mjs:376–416,462–473`). Guarding the invented name would leave the real path untouched.
